# Example Hooke configurations

Copy one of these files to a project root as `hooke.toml`, edit the prompts, then run `hooke deploy` from that directory. See the README for the full field reference and `hooke init` for a commented skeleton in your own project.

- [`scheduled.toml`](scheduled.toml) — periodic automations (schedules only)
- [`watch.toml`](watch.toml) — file-triggered automations (watchers only)
